Plugins
A plugin is JavaScript that runs with a delta object: delta.on('track'|'state', fn), delta.css(text), delta.addButton(label, fn), delta.player. Only add code you trust.
Privacy
Delta has no analytics or trackers. It only contacts services you use: Spotify, SoundCloud, lrclib.net (lyrics), and cdnjs (tag reader). Library files stay on this device.
